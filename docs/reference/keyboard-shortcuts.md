# Keyboard shortcuts

## Asset grid

The grid is fully keyboard-navigable. **Tab** into it first, then:

| Key | Action |
| --- | --- |
| **← → ↑ ↓** | Move focus between assets |
| **Home / End** | Jump to the first / last asset |
| **Enter** | Open the focused image (or select it) |
| **Space** | Toggle the focused asset in your multi-selection |
| **Shift + Arrows** | Extend the selection |
| **⌘A** | Select all assets in the current view |
| **F** | Favorite / unfavorite the focused asset |
| **Delete / Backspace** | Delete the focused asset (or the multi-selection) |
| **Esc** | Clear the current selection |

## Boards

The board canvas is primarily pointer-driven. Common actions:

| Action | How |
| --- | --- |
| **Pan** | Drag empty canvas |
| **Zoom** | Scroll / trackpad pinch (centers on cursor) |
| **Marquee-select** | Drag a box across items |
| **Connect two items** | Select two → **CONNECT** in the toolbar |
| **Free-draw** | Toggle **DRAW**, then drag on the canvas |

## Dialogs

| Key | Action |
| --- | --- |
| **Esc** | Cancel / close a dialog |

:::note[Deliberately no "Enter to confirm" on delete]
Confirmation dialogs for destructive actions don't trigger on **Enter** — so a reflexive keypress can't delete something. Click the confirm button (or **Esc** to cancel).
:::
