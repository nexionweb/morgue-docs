# Palette builder

The palette builder lets you create palettes from scratch or refine ones that came in with a capture.

## Creating a palette

1. Open the **Palette builder**.
2. Add colors — by hex value or by picking.
3. Name the palette and save it. It joins your library as a palette asset.

## Editing colors

- Add, remove, and reorder colors.
- Edit a color's hex value directly.
- Save your changes back to the palette.

## Reusing palettes

- Saved palettes live in your library and show up in the grid (filter to **Palettes**).
- Pull a saved palette's colors into your work by **[copying any hex](/palettes-fonts/copying-colors)**.
- Find palettes (and assets that use a color) with **[color search](/organizing/search)**.

:::tip[Turn a capture into a working palette]
Captured a site whose colors you love? Open its palette, refine it in the builder (drop the off-brand colors, keep the core), and you've got a clean, reusable palette for your own project.
:::
