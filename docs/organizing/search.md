# Search & color search

Two ways to find things: **text search** for words, and **color search** for, well, color.

## Text search

Use the search box at the top of the sidebar to match across:

- **Name** of the asset
- **Tags** it carries
- The **site** it was captured from
- **Fonts** detected on it

Results filter the grid live as you type. Clear the search to return to the full view.

## Color search

Morgue can find every asset that **contains a particular color** — invaluable when you're matching a palette or hunting for "that teal I saw somewhere."

1. Pick a color to filter by (from the color filter in the grid toolbar, or a swatch you're working with).
2. Morgue shows assets whose palette includes that color.

### Tolerance

Color search has an adjustable **tolerance** so you control how exact the match is:

| Tolerance | Matches |
| --- | --- |
| **Exact** | Only very close color matches |
| **Close** | Nearby shades (a good default) |
| **Loose** | A wider range around the color |

:::tip[Loosen up when you're exploring]
Start at **Close**. If you're casting a wide net for inspiration, switch to **Loose**; if you're matching a brand color precisely, use **Exact**.
:::

## Combine them

Text and color filters work together — e.g. filter to a tag, then narrow by color — so you can zero in on exactly the reference you remember.
