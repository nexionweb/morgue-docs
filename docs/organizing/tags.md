# Tags

Tags are labels that cut **across** folders. Where a folder says *where something lives*, a tag says *what it's about* — and an asset can have as many as you want.

## Adding tags

- Select an asset and add tags like `hero`, `pricing`, `dark-mode`, `typography`.
- Reuse the same tags consistently and your library becomes filterable by theme.

## Filtering by tag

- Click a tag in the sidebar's **Tags** section to see every asset carrying it — regardless of which folder it's in.
- Combine tags with **[search](/organizing/search)** to narrow further.

## Managing tags

- **Rename** a tag to update it everywhere it's used.
- Use **multi-select mode** (the **SELECT** control on the Tags header) to delete several tags at once. Deleting a tag removes the label; your assets stay.

:::tip[Build a small, consistent vocabulary]
A handful of tags you use *consistently* beats hundreds you use once. Decide on a short set — by component (`hero`, `footer`, `pricing`), by style (`brutalist`, `minimal`), or by mood — and stick to it.
:::
