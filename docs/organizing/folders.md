# Folders

Folders are the structural backbone of your library — the place an asset *lives*. They're nestable, so you can mirror how you actually think about your work (clients, projects, categories).

## Creating a folder

1. In the sidebar, find the **Folders** section.
2. Click the **+** to add a folder and give it a name.
3. To nest, add a subfolder **under** an existing folder.

## Moving assets into folders

- **Drag** an asset (or a multi-selection) from the grid onto a folder in the sidebar.
- An asset can live in a folder while still being found by its **tags** and by **search**.

## Organizing the tree

- **Nest** folders to any depth that makes sense.
- **Reorder** and **rename** folders from the sidebar.
- Use **multi-select mode** (the **SELECT** control on the Folders header) to act on several folders at once.

:::tip[Folders vs. tags]
If you're unsure whether something should be a folder or a tag, ask: *"Is this where it lives, or is it a theme that spans many places?"* Where it lives → folder. A theme → **[tag](/organizing/tags)**.
:::

## Deleting folders

Deleting a folder removes the **container**, not your assets — the images, palettes, and fonts inside stay in your library. See bulk deletion in **[Organizing overview](/organizing/overview)**.
